Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

The Windows installers of the Amberwave client and the Amberwave server, and the programs Amberwave builds itself inside them. They are built by GitHub Actions from the public repository lfrank95/amberwave. Third-party components shipped inside the installers (PHP, nginx, MariaDB, ffmpeg, cloudflared, Electron) keep their upstream form.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The services the Amberwave server can contact, and when, are listed in the software privacy policy.
