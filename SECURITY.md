# Security

Amberwave can be reachable from the internet (remote streaming, remote control). Please report security problems
**privately** via GitHub: *Security → Report a vulnerability* in this repository
(https://github.com/lfrank95/amberwave/security/advisories/new). Do not open a public issue.

Supported versions during the beta: only the latest `0.9.x` beta release gets fixes.

Please include the version, what an attacker can do, and steps to reproduce. You will get an answer within a few days.
