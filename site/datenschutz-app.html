Datenschutz der Software

English version ↓Datenschutz dieser Website

Das Wichtigste

  • Amberwave läuft auf deinem eigenen Server. Deine Musik, Konten, Playlists und Hördaten bleiben dort.
  • An mich als Entwickler schickt die Software nichts: keine Telemetrie, keine Nutzungsstatistik, keine Absturzberichte, keine Zählung von Installationen.
  • Es gibt keine Werbung, keine Analyse-Bibliotheken und keine Amberwave-Konten bei mir.
  • Verantwortlich für die Daten auf einem Amberwave-Server ist, wer ihn betreibt.

Apps auf deinen Geräten

  • Android-App und Windows-Client verbinden sich nur mit dem Server, den du einträgst. Zum Finden des Servers fragen sie Geräte im eigenen Heimnetz an. Außerdem prüfen sie bei GitHub, ob es eine neue Version gibt.
  • Offline gespeicherte Musik, Cover und Einstellungen liegen nur auf dem Gerät und werden beim Deinstallieren gelöscht.
  • Web-App: Sie wird von deinem Server geladen. Sie setzt nur die für die Anmeldung nötigen Cookies und speichert Einstellungen im Browser.
  • Nutzt du den Fernzugriff, laufen die Verbindungen der Apps über Cloudflare (siehe oben).

Software privacy

Deutsche Fassung ↑Website privacy (German)

In short

  • Amberwave runs on your own server. Your music, accounts, playlists and listening data stay there.
  • The software sends nothing to me as the developer: no telemetry, no usage statistics, no crash reports, no install counting.
  • There are no ads, no analytics libraries and no Amberwave accounts with me.
  • Whoever runs an Amberwave server is responsible for the data on it.

Where the server connects

With each of these connections the service learns your server's IP address. The provider's own privacy policy applies.

Apps on your devices

  • The Android app and the Windows client only connect to the server you enter. To find it they query devices on your own home network. They also check GitHub for a new version.
  • Music, covers and settings saved for offline use stay on the device and are deleted when you uninstall.
  • Web app: it is loaded from your server. It only sets the cookies needed to sign in and keeps settings in the browser.
  • If you use remote access, the apps' connections pass through Cloudflare (see above).
